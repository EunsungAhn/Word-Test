# 일본어 한자 풀이 데이터

`kanji.json`은 `public/{japanese,hackers_n3,darakwon_n3,darakwon_n4,joayo}/*.txt`의 단어 열에서 추출한 한자를 키로 사용한다.
기존 단어장 TXT의 내용과 형식은 유지한다. 동일 한자를 사용하는 모든 단어가 한 항목을 공유한다.

- 출처: 네이버 **일본어사전**의 한 글자 항목, 한국한자 표기.
- `reading`: 괄호 안의 한국어 훈음을 슬래시 등 원문 구분 기호와 함께 보존.
- `koreanHanja`: 사전이 제공한 한국 한자. 일본식 자형과 다를 수 있다.
- `sourceUrl`, `checkedAt`: 확인한 항목의 원문 주소와 확인 날짜.
- `status: verified`: 한국 한자 훈음을 확인함.
- `status: no-korean-reading`: 한국 훈음이 없으므로 해당 사전의 뜻풀이 `meaning`과 안내 `note`를 표시.
- `status: unavailable`: 해당 사전에서 단자 훈음을 확인하지 못함. 추측 없이 안내를 표시.

최초 일본어 메뉴: 65개 파일, 961자(훈음 959자, 예외 働/珊 2자).
2026-11-11 교재 메뉴 확장 후: 총 1,341자 중 출처를 확인한 항목 1,328자(예외 2자 포함), 단자 훈음을 확인하지 못한 항목 13자.
남은 224자를 간격을 두고 모두 재조회해 208자의 훈음을 추가했고, 유니코드 호환 한자 3자는 기존 네이버 출처와 연결했다. 이번 조회에서는 연결 오류가 발생하지 않았다.
한자를 새로 추가하면 네이버 일본어사전에서 표기를 직접 확인하고 출처와 함께 추가한다.
학습 중에는 네이버에 요청하지 않고 이 데이터를 로컬 번들에서 읽는다.
`KanjiCoverage.test.js`가 단어장에 등록되지 않은 한자가 생기면 알려준다.

교재 메뉴 전체에 같은 기능을 연결한다. `kanji-pending.json`은 네이버 일본어사전 검색 결과에서 단자 훈음을 아직 확인하지 못한 글자의 목록이며, 이 항목에는 훈음을 추정해서 입력하지 않는다. 화면에서는 클릭 시 확인 전 상태를 표시한다.
